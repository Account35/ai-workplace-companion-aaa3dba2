# AI Workplace Productivity Assistant

## 📌 Project Overview

**AI Workplace Productivity Assistant** is a modern, responsive AI-powered web application designed to help professionals improve workplace productivity and communication.

The application provides AI-powered tools for generating professional emails, summarizing meeting notes, and assisting users with everyday workplace tasks.

The application is designed as a lightweight, accessible productivity tool that **does not require user registration or sign-in**.

---

## ✨ Features Implemented

### 📧 Smart Email Generator

Generate professional emails using AI based on the user's:

* Recipient or audience
* Email purpose
* Key points
* Preferred tone

Supported tones:

* Formal
* Friendly
* Persuasive

Generated emails include an editable subject and email body, with options to:

* Copy
* Regenerate
* Clear

---

### 📝 Meeting Notes Summarizer

Analyze meeting notes using AI and automatically extract:

* Meeting summary
* Key decisions
* Action items
* Deadlines

The generated results are editable and can be copied, regenerated, or cleared.

---

### 🤖 AI Workplace Assistant

An interactive AI chatbot designed to assist with common workplace tasks.

Users can ask questions or request assistance with:

* Professional communication
* Email drafting
* Meeting agendas
* Task organization
* Message improvement
* Information summarization
* Workplace brainstorming

Responses are dynamically generated by AI based on the user's prompts rather than using predefined responses.

---

### 📊 Modern Dashboard

The application includes:

* Professional SaaS-style dashboard
* Sidebar navigation
* Feature cards
* Responsive layouts
* Clean light-grey and dark visual design
* Loading and error states
* Editable AI-generated content

---

### 🛡️ Responsible AI

The application includes a Responsible AI disclaimer informing users that AI-generated content should be reviewed before being used for professional communication or decision-making.

Users are also encouraged not to enter confidential or sensitive workplace information.

## 🚀 Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/ai-workplace-productivity-assistant.git
```

### 2. Navigate to the Project

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure the AI Integration

Set up the required AI API integration according to the project's AI provider configuration.

If environment variables are required, create a `.env` file and add the required configuration.

Example:

```env
VITE_AI_API_KEY=your_api_key_here
```

**Do not commit API keys or other secrets to GitHub.**

### 5. Start the Development Server

```bash
npm run dev
```

The application should now be available through the local development URL displayed in your terminal.
